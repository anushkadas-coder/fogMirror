# fogMirror (hand tracking)

Run: open a terminal in this folder and run  py -m http.server 8000
     then open http://localhost:8000 in Chrome or Edge and allow the camera.

Gestures
  ☝️  Index finger only      draw on the glass
  🖐️  Open palm, hold ~1s     clear everything (a ring fills up)
  👌  Pinch + other fingers up  set brush size: hand high = big, low = small

Recording
  ⏺ record starts, ⏹ stop saves a video to Downloads.
  The helper dots and ring are hidden in the recording.
